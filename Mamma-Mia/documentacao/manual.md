# Manual de utilização — Mamma Mia

## Abrir o sistema
Abra `index.html` no navegador ou execute a pasta com uma extensão de servidor local, como Live Server.

## Fazer um pedido de demonstração
1. Acesse a seção **Escolha sua pizza**.
2. Clique em **Adicionar +** nos sabores desejados.
3. Vá para **Finalize seu pedido**.
4. Confira os itens e use os botões `+` e `−` para ajustar quantidades.
5. Preencha nome, telefone e endereço.
6. Se necessário, escreva observações.
7. Clique em **Enviar pedido**.
